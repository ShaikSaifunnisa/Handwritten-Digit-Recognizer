How this differs from the Python script

Your script trains on the full 60,000-image MNIST set for up to 10 epochs using Keras. A browser tab can't comfortably do that, so this version trains a smaller version of the same architecture on a subset of about 8,000 digits for a handful of epochs — enough to recognize clear handwriting in a few seconds, without keeping you waiting. Refresh the page to train a fresh model.
